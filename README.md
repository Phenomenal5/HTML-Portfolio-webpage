# Portfolio Webpage Project

Welcome to my portfolio webpage project! This repository contains the completed work for my assignment where I practiced modern HTML techniques to build a personal portfolio website. The goal was to create a well-structured, accessible, and visually appealing webpage while incorporating new web development skills.

---

## Project Overview

In this project, I built a portfolio webpage using semantic HTML and best practices. The page is designed to showcase personal information, work samples, and more using the following key features:

- **Semantic Tags:** Organized the page with meaningful HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
- **Media Integration:** Included a video/audio element on the page to enhance the multimedia experience.
- **Local Links, Lists, or Tables:** Structured content using local navigation links, and utilized lists and tables where appropriate.
- **HTML Forms:** Created an interactive Contact section with an HTML form for visitors to reach out.

---

## Checkpoint Instructions

As part of the assignment, the following tasks were completed:

1. **Navbar Creation:**  
   - A navigation bar was created with links for **Home**, **About**, **Work**, **Resume**, and **Contact**.

2. **Section Development:**  
   - **About Section:** Introduces personal details and background information.  
   - **Work Section:** Showcases projects and professional work.  
   - **Resume Section:** Presents a summary (or full view) of my resume and career achievements.  
   - **Contact Section:** Features an HTML form where visitors can submit queries or messages.

3. **Page Footer:**  
   - A footer was added to the bottom of the page to complete the overall design.
